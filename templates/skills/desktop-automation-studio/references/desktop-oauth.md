# Desktop OAuth case study

- Browser Google Auth Platform setup showed app name and support email completed.
- Mouse clicks on the External audience radio did not visibly select it, even when input returned success.
- Keyboard Tab/Enter successfully navigated an earlier branding form; keyboard focus must be verified per step.
- Do not claim the Gmail OAuth client or authorization exists until client.json/token.json are confirmed privately and the provider status succeeds.
- Keep OAuth consent in the official browser; do not bypass consent or read credentials.
- Verify any requested email with a real API send receipt, including recipient and attachment metadata.
