# Browser Contrast Audit`n`nRun contrast_audit.js in the rendered page to evaluate direct text nodes using computed foreground/background colors, alpha compositing, relative luminance, and WCAG-style contrast thresholds. Normal text requires 4.5:1; large text requires 3:1. Treat results as objective contrast evidence, not a complete accessibility certification. Complex backgrounds such as images/gradients require additional visual review.
