# Direction Boards`n`nDirection Boards create 2-5 isolated UI Forge draft workspaces for genuinely different experience directions. Each direction must attach screenshot, browser-proof, and score evidence with SHA-256 integrity before selection. Selection refuses missing/tampered evidence and live-source drift. Selection is intentionally non-merging: it records the chosen draft with merge_performed=false; inspect and accept through the normal conflict-aware draft workspace path separately. Store proof under .synapse/ui-forge so proof artifacts do not alter the source fingerprint.
