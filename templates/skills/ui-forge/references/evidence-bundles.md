# Evidence Bundles`n`nFreeze UI Forge proof artifacts with evidence_bundle.py. A bundle copies browser screenshots, audits, State Matrix results, score reports, or other proof under .synapse/ui-forge/evidence, records SHA-256 for every artifact, records the project source fingerprint, and hashes the manifest itself. verify fails on artifact or manifest tampering. Evidence storage is excluded from the project source fingerprint so producing proof cannot create source drift.
