# webgl-shader-studio

## When to use
Use this skill when a Synapse project requires the named 3D technology.

## Workflow
1. Inspect project files, versions, existing assets and concurrent edits.
2. Implement in a reproducible isolated lane.
3. Keep source Blender files, export optimized GLB, and verify imports.
4. Validate scene geometry, textures, material response and rendering performance.
5. Preserve accessible controls and scrolling behavior.
6. Run browser and visual QA; report evidence and limitations.
7. Capture lessons in the pack for reuse.

## Synapse brain
Use renderer/assets/brain-reference-realistic.png as visual target, not a 3D source. Preserve Brain3D interactive navigation, drag, and zoom controls.
