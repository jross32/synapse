# Synapse AI project workflow — mandatory

1. **Resolve context before coding.** Call `synapse_get_context`, then `synapse_list_projects`; for a known app call `synapse_get_project_ai_context(project_id)` and `synapse_get_project_records(project_id)` before scanning files. Look up existing decisions, paths, prior tests, and unfinished work. Reuse memory instead of re-reading the entire repository.
2. **Register new or previously unlisted apps.** Use `synapse_register_project(project_id, name, path)` with a validated existing, **absolute** directory. The registration grants project-scoped image generation and shared AI memory. Re-registration with the same ID and canonical path is safe. Never register a filesystem root or create directories implicitly. For creating a new app, first deliberately create its directory through an approved build workflow, then register it.
3. **Always supply an absolute path and cwd** in coding prompts, command calls and delegated specs. Never rely on the default cwd. On Windows, use e.g. `cwd: C:\\Users\\justi\\ExampleApp`; on POSIX use an absolute path. Never run unreviewed commands in Synapse's root when the project is elsewhere.
4. **Use async commands for installs/builds/tests.** Run `synapse_run_command_async(command, cwd=absolute_path, timeout_seconds=...)` for `npm install`, `npm ci`, `npm run build`, large test suites and anything expected to take more than seconds. Poll `synapse_get_command_result(job_id)`, and check the actual final exit code; don't treat a returned job ID as success. The synchronous tool has a 90-second transport ceiling.
5. **Persist the handoff.** After a milestone or blocker, call `synapse_capture_note(project_id, content, destination="ai_context")` summarizing concrete outcome, files, tests, decisions and next action. Do not store secrets, raw access tokens or customer private data. Avoid redundant verbose notes.
6. **Use project-scoped media tools.** `synapse_generate_image` writes only under registered project roots; use project-relative paths and audit provenance. Register apps before attempting generation.

These instructions apply to ChatGPT, Claude, Copilot, Codex and delegated workers when operating through Synapse.
