Support & Repair

Having issues? The installer can repair and restore your Synapse installation.

Repair Installation

Run the installer again. If Synapse is already installed, select Repair / update existing installation to restore missing files and update components.

Check Connection

If account services are unavailable, test the connection directly. A timeout is not necessarily your internet.

Test account service ↗

Repair Reports

Synapse checks installed files, daemon status, DNS/TLS, storage, permissions, and configuration. View detailed reports in your local folder.

%LOCALAPPDATA%\Synapse\repair-reports

Repair preserves project databases and credentials. Active jobs are not forcibly terminated.
