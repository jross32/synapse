SUPPORT & REPAIR

Having trouble? Repair Synapse.

You do not need to uninstall first. The Windows installer can detect an existing copy, restore missing application components, and preserve your projects and settings.

1. Run the installer again

Download the current Windows installer above. If Synapse is already installed, select Repair / update existing Synapse installation.

2. Check your connection

If sign-in says the account service is unavailable, test the service directly. A connection issue is not necessarily an internet outage.

Test account connection ↗

3. View the repair report

Synapse checks installed files, its daemon, DNS/TLS, storage, permissions, and configuration. Some issues need your approval rather than automatic changes.

%LOCALAPPDATA%\Synapse\repair-reports

Repair does not erase project databases or credentials. Active jobs are not forcibly terminated. If an issue remains, use the report to identify the cause.
