Get started with Synapse

2. Install and create an account

Run the installer, launch Synapse, then choose the account creation option in its onboarding screen. Enter your own username, email, and password. Existing users should sign in instead.

Account creation is currently performed inside the desktop application. This static website does not collect passwords or create accounts, and it will not ask you to paste access tokens.

3. Connect your workspace

Sign in on the computer you want to authorize. Review device permissions before granting an AI worker access. Connect only the AI providers and tools you intend to use.

Account preferences and registered devices can sync. Local project files are not automatically copied to other computers.

4. Verify your installation

Open the app, confirm the account session and device appear correctly, then test a small authorized operation. For updates, back up local projects and use the release notes to check compatibility first.

If sign-in or setup fails, use support and repair instructions. If an unsigned preview triggers an operating-system warning, verify the official GitHub release and checksum before proceeding. Do not disable operating-system security globally.
